
# TODAY

The current architecture shows a Transceiver Module connected to a Switch Motherboard via Optical I/O. The Transceiver Module contains three main components stacked vertically: Optics (orange section at top), DSP (black section in middle), and PCB (green section at bottom). An orange optical connection line enters the Optics section from the left.

The Switch Motherboard contains an Optical I/O section (gray) that connects to the Transceiver Module, followed by a Retimer section (black) and an ASIC section (black), all mounted on a PCB (green base).

# FUTURE

The future architecture shows a more integrated approach with a Switch CPO (Co-Packaged Optics) design. The optical connection (orange line) connects directly to an integrated module containing Optics (orange section) and ASIC (black section) mounted on a Substrate (teal/blue section), which sits on the Switch Motherboard's PCB (green base).

This future design eliminates the separate Transceiver Module, DSP, and Retimer components, creating a more streamlined and integrated solution where the optics and processing are co-packaged together.
