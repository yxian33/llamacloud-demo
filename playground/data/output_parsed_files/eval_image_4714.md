

# Dividend Yield Comparison: European Infrastructure vs MSCI Europe ex-Financials

| Jan 2015 | 4.8%                    | 3.1%                      |
| Jan 2016 | 4.2%                    | 2.9%                      |
| Jan 2017 | 4.5%                    | 3.1%                      |
