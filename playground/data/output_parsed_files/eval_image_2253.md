
# Japanese Corporate Financial Metrics and Policy Timeline (1990-2023)

## Key Policy Milestones

- **2013**: Japan Revitalization Strategy
- **2015**: Corporate Governance (CG) Code comes into effect  
- **2018**: CG Code revisions
- **2021**: CG Code revisions
- **2023**: TSE's 'Request'
