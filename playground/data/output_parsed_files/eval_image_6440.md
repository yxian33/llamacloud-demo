
## Time Series Forecasting Chart

**Legend:**
- Actual Data (solid blue line)
- SARIMA Forecast (red dashed line)

| Data Series     | Line Style  | Color | Description                                                                                                                                                                                                                                  |
| --------------- | ----------- | ----- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Actual Data     | Solid line  | Blue  | Historical time series data showing cyclical patterns with peaks and valleys. The data starts low, rises to a peak in the early-middle portion, declines to a trough, then shows a strong upward trend toward the end with some fluctuation. |
| SARIMA Forecast | Dashed line | Red   | Forecasted values extending beyond the actual data period, showing a continued upward trend from where the actual data ends.                                                                                                                 |


The chart displays a time series analysis where the actual data exhibits seasonal or cyclical behavior, and the SARIMA (Seasonal Autoregressive Integrated Moving Average) model provides forecasted values that continue the observed trend pattern.
