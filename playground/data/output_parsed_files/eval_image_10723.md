## Complexity Factors

F (Complexity) = {Compute Performance, Network Bandwidth, Memory Bandwidth, Power Delivery, Thermal Integrity, Mechanical Reliability}

The complexity factors are represented by six categories:
- Compute Performance
- Network Bandwidth  
- Memory Bandwidth
- Power Delivery
- Thermal Integrity
- Mechanical Reliability
