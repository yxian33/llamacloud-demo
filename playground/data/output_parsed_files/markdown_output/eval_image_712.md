
# How AMI works

An advanced metering system uses a wireless network to provide detailed data that is easily accessible online by customers and staff.

```mermaid
flowchart TD
    A[Advanced water meters<br/>transmit hourly water use<br/>data over a wireless network] 
    B[Cloud-based Data Processing<br/>with Analytics and Security]
    C[Customers<br/>can access data<br/>from the web portal]
    D[City staff can access data<br/>and more detailed reports<br/>about water use in the City]
    
    A -->|Wireless Network| B
    B -->|Web Access| C
    B -->|Detailed Reports| D
```

Advanced water meters transmit hourly water use data over a wireless network.

Customers can access data from the web portal.

City staff can access data and more detailed reports about water use in the City.
