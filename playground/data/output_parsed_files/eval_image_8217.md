

# Nifty P/E Ratio Chart (2012-2023)

| Time Period | Nifty P/E One Year Forward | Key Observations                                        |
| ----------- | -------------------------- | ------------------------------------------------------- |
| Jan 2012    | \~13.5                     | Starting point of the chart                             |
| 2012-2013   | 11.5-14.0                  | Initial volatility, lowest point around 11.5            |
| 2013-2014   | 13.0-14.0                  | Gradual stabilization                                   |
| 2014-2015   | 14.0-16.5                  | Upward trend begins                                     |
| 2015-2016   | 15.0-17.0                  | Continued growth with volatility                        |
| 2016-2017   | 16.0-17.0                  | Relatively stable around upper range                    |
| 2017-2018   | 17.0-18.5                  | Further upward movement                                 |
| 2018-2019   | 17.0-19.0                  | Increased volatility, reaching higher levels            |
| 2019-2020   | 16.0-19.0                  | Sharp drop around early 2020 (pandemic impact)          |
| 2020        | 11.5-19.0                  | Extreme volatility, sharp drop to \~11.5, then recovery |
| 2020-2021   | 18.0-22.5                  | Strong recovery and growth to peak levels               |
| 2021-2022   | 19.0-23.0                  | Peak levels around 22.5-23.0                            |
| 2022-2023   | 17.0-20.5                  | Moderation from peak levels                             |
