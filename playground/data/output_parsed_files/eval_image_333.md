# Main Challenge for 3200G is Power

| Technology | 800G (Watt) | 1600G (Watt) | 3200G (Watt) |
| ---------- | ----------- | ------------ | ------------ |
| LPO        | \~6         | \~10         | \~20         |
| LRO        | \~12        | \~15         | \~30         |
| DSP2       | \~11        | \~20         | \~40         |
| DSP        | \~15        | \~25         | \~50         |


LPO and LRO provide the lowest power solutions for 3200G Optics Modules

DSP2 assumes 2nm DSP and low power modulators (2026/2027 timeframe)
