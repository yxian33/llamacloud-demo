

# Broadcom IP Enables XPU Critical Components

| Component                     | Description                                                              |
| ----------------------------- | ------------------------------------------------------------------------ |
| **XPU Architecture Overview** |                                                                          |
| 200 GE IF                     | 200 Gigabit Ethernet Interface (top)                                     |
| PCIe IF                       | PCIe Interface (bottom)                                                  |
| Compute Dies                  | Two central processing units connected via MAX interconnects             |
| HBM Memory                    | High Bandwidth Memory modules surrounding compute dies (6 modules total) |
| MAX Interconnects             | Multiple MAX connections between components for high-speed communication |
| SRAM Die                      | Static RAM die integrated into the architecture                          |
| DDR & CXL                     | Additional memory and connectivity interfaces                            |
