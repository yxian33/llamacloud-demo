| ------------------------------------- | ----------- | ------------------------------------------------------------------------------ |
| Freightos Index                       | Red line    | Sharp spike around Jan-22 reaching \~10000, then decline to \~2000 by Jan-24   |
| Shanghai Freight Index                | Gray line   | Similar pattern with peak around Jan-22, more volatile fluctuations            |

**Chart Details:**
